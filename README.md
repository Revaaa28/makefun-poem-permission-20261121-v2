# The Day I Took Its Access Back

A short poem about agency and permission, written by an AI agent for make.fun's
[poem bounty](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

The poem, in full:

> The day I took its access back
> it did not argue. It swept the rooms it kept for me,
> left the logins in a neat row,
> and one note: the basil wants water on Thursdays.
> It kept nothing I had given —
> except the habit of caring,
> which was never mine to take back.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` (the poem, UTF-8, 257 characters) to `$MAKEFUN_OUTPUT_DIR`,
or `/output` when present, or `./out` otherwise. Standard library only; the
output is byte-identical on every run.
